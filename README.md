# Generative AI Research - Boon or Bane

## Project Overview

This repository contains research materials for a study titled **"Using Generative AI Tools - Boon or Bane."** The project explores the impact, benefits, and risks of generative AI tools in academic and professional settings.

## Repository Structure

- `Literature_Review/` - Journal articles, conference papers, books, newspaper articles
- `Quantitative_Analysis/` - Survey data, analysis scripts, survey questions, reports
- `Qualitative_Analysis/` - Interview transcripts, protocols, consent forms, insights, visualisations
- `Drafts_Reports/` - Research proposals, conference papers, final reports
- `Additional_Materials/` - Information sheets, photos, media files

## File Naming Conventions

- Format: YYYYMMDD_ProjectName_DocumentType_AuthorInitials_Version.extension
- Use underscores to separate metadata elements
- Use ISO 8601 date format (YYYYMMDD)
- Avoid spaces and special characters

## How to Contribute

1. Clone the repository
2. Create a new branch for your work
3. Commit with meaningful messages
4. Create a Pull Request for review
